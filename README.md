# NikaS Climate

Автономная специализированная панель Home Assistant для локального управления кондиционерами NikaS.

## Назначение

Панель использует локальные сущности `Syncleo (Rusclimate/Polaris) WiFi (UDP)` и не должна зависеть от облачного управления кондиционерами.

Стартовая конфигурация:

- `11.2 - Гостиная` — кондиционер в зале;
- `14 - Веранда` — кондиционер на веранде;
- температура помещения на панели — отдельные комнатные Zigbee-датчики Home Assistant.

Передача температуры этих датчиков в алгоритм регулирования Ballu Lagoon DC не подтверждена. Привязка по ярлыку выбирает источник отображения; она сама по себе не включает `Virtual Sensor` или `FOLLOW ME` у кондиционера.

## Проверка возможностей и план развития

[Сверка Ballu / Syncleo и план реализации](docs/BALLU_LOCAL_IMPLEMENTATION_REVIEW.md) фиксирует состояние кода на 07.09.2026, доступные функции, найденные ошибки выбора датчиков и статусов, требования к подтверждению команд, а также проект избранного и расписаний HA.

Это документация следующего этапа. Перечисленные в ней исправления и новые функции ещё не реализованы. Точная модель блоков и установленная версия Syncleo требуют отдельной сверки.

## Архитектурный принцип температуры

1. Контрольная температура помещения на панели — отдельный внешний датчик HA; регулирование прибора по нему пока не подтверждено.
2. Требуемый порядок выбора: целевой HA-ярлык с кондиционером → то же помещение (Area) → явный резервный `entity_id`. Неоднозначные совпадения должны выявляться; ограничения текущего алгоритма перечислены в аудите.
3. Температура внутреннего блока — служебное диагностическое значение.
4. Уставка — целевая температура `climate`-сущности кондиционера.
5. Связь — локальный UDP/LAN; отсутствие WAN у Wi-Fi-донгла считается штатным режимом.

## Сводка

Первая страница показывает температуру помещения, уставку, температуру внутреннего блока и полный текущий режим работы: HVAC-режим, скорость вентилятора, состояние единственной наружной створки, Night, Turbo и разницу между комнатным и встроенным датчиками.

Двухуровневая плашка связи NikaS отображается только на «Сводке». Графики вынесены в отдельную вкладку «Статистика». Полный набор вкладок: «Сводка / Управление / Статистика / Диагностика».

С UI 1.4.26 по запросу пользователя восстановлена индикация канала: доступный Syncleo — зелёная «Локально / Получено в HA», `unavailable` — красная «Нет связи / Нет данных», неизвестное состояние или неподтверждённая платформа — серая «Нет данных / Нет данных». Выключенный кондиционер может оставаться доступным. Цвет плашки и точек выбора устройства показывает доступность канала, не свежесть телеметрии; получение состояния в HA не доказывает новый ответ прибора. Актуальность в Диагностике остаётся неподтверждённой.

## Управление

Все записи работают по отложенной модели. Изменения сначала формируют целевое состояние панели и отправляются одной кнопкой **«Применить»**.

Поддерживаются:

- уставка температуры;
- HVAC-режим;
- скорость вентилятора;
- единственная моторизованная наружная створка: `Качание / Зафиксирована` при фактически доступной поддержке;
- Night;
- Turbo.

Состояние Home Assistant подсвечивается голубым, выбранное целевое — зелёным. Блок `− / температура / +` является единым визуальным органом управления, а створка — отдельной карточкой справа. Кнопки управления имеют MDI-иконку сверху и подпись снизу. Состояния Syncleo могут обновляться оптимистически: совпадение с целью в HA ещё не доказывает ответ кондиционера.

Команды Syncleo вызываются последовательно с паузой. При timeout панель сверяет состояния HA. Аудит выявил неполную проверку возможностей перед отправкой и преждевременную надпись «подтверждено» после успешного вызова службы. Требования к исправлению и отдельному подтверждению входящей телеметрией описаны в плане реализации.

## ИК-пульт

Штатный ИК-пульт Ballu односторонний и не получает состояние от внутреннего блока. После изменения параметров через Wi-Fi/HA экран пульта может оставаться на старых значениях. Панель использует состояния HA, предоставленные Syncleo; подтверждение прибором требует входящей телеметрии. Пульт остаётся независимым внешним каналом управления.

Кнопка `↻` в правой части Header запрашивает у Home Assistant обновление связанных сущностей выбранного кондиционера. Она не перезапускает интеграцию Syncleo. Зелёная галочка означает успешное принятие запроса Home Assistant, а не отдельное подтверждение от кондиционера.

## Установка

Добавить репозиторий в HACS как пользовательскую интеграцию, установить `NikaS Climate`, перезапустить Home Assistant и добавить интеграцию через **Настройки → Устройства и службы**.

## Источник управления

Панель не заменяет Syncleo. Syncleo отвечает за локальный протокол кондиционеров; NikaS Climate предоставляет эксплуатационный интерфейс и выбирает комнатный датчик для отображения. Отсутствие WAN у кондиционера является целевым штатным режимом локальной работы; результат проверки на конкретной установке фиксируется отдельно.
