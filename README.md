# NikaS Climate

Автономная специализированная панель Home Assistant для локального управления кондиционерами NikaS.

## Назначение

Панель использует локальные сущности `Syncleo (Rusclimate/Polaris) WiFi (UDP)` и не должна зависеть от облачного управления кондиционерами.

Стартовая конфигурация:

- `11.2 - Гостиная` — кондиционер в зале;
- `14 - Веранда` — кондиционер на веранде;
- внешний контроль температуры — комнатные Zigbee-датчики, переданные в Syncleo как `Virtual Sensor`.

## Архитектурный принцип температуры

1. Контрольная температура помещения — внешний датчик HA / Virtual Sensor Syncleo.
2. Поиск контрольного датчика: общий HA-ярлык с кондиционером → то же помещение (Area) → явный резервный `entity_id`.
3. Температура внутреннего блока — служебное диагностическое значение.
4. Уставка — целевая температура `climate`-сущности кондиционера.
5. Связь — локальный UDP/LAN; отсутствие WAN у Wi-Fi-донгла считается штатным режимом.

## Сводка

Первая страница показывает температуру помещения, уставку, температуру внутреннего блока и полный текущий режим работы: HVAC-режим, скорость вентилятора, состояние единственной наружной створки, Night, Turbo и разницу между комнатным и встроенным датчиками.

Эталонная двухуровневая плашка связи NikaS/S8 OMNI отображается только на «Сводке». В нижней части сводки отображается компактный график изменения температуры помещения за 24 часа из Recorder Home Assistant, вместе с уставкой при наличии исторических атрибутов climate.

## Управление

Все записи работают по отложенной модели. Изменения сначала формируют целевое состояние панели и отправляются одной кнопкой **«Применить»**.

Поддерживаются:

- уставка температуры;
- HVAC-режим;
- скорость вентилятора;
- единственная моторизованная наружная створка: `Качание / Зафиксирована`;
- Night;
- Turbo.

Текущее состояние подсвечивается голубым, выбранное целевое — зелёным. После подтверждённого обновления Home Assistant цель становится текущим состоянием. Кнопки управления имеют MDI-иконку сверху и подпись снизу.

## ИК-пульт

Штатный ИК-пульт Ballu односторонний и не получает состояние от внутреннего блока. После изменения параметров через Wi-Fi/HA экран пульта может оставаться на старых значениях. Поэтому источником фактического состояния панели считается Syncleo, а пульт — независимым внешним каналом управления.

Кнопка `↻` в правой части Header предназначена для принудительного обновления выбранного устройства: обновляются связанные сущности, а при доступном `config_entry_id` выполняется перезагрузка выбранного Syncleo config entry для повторного локального handshake.

## Интеграция

- Domain: `nikas_climate`
- Integration: `NikaS Climate`
- Version: `0.1.4`
- UI: `v1.2.0`
- Route: `/dashboard-climate-v1/home`

## Установка

Добавить репозиторий в HACS как пользовательскую интеграцию, установить `NikaS Climate`, перезапустить Home Assistant и добавить интеграцию через **Настройки → Устройства и службы**.

## Источник управления

Панель не заменяет Syncleo. Syncleo отвечает за локальный протокол кондиционеров; NikaS Climate предоставляет эксплуатационный интерфейс, связывает кондиционер с контрольным датчиком помещения и не требует облачного канала для штатного управления.
