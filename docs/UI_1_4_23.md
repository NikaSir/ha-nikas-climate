# UI 1.4.23 / интеграция 0.1.52

Плашка связи приведена к логике и геометрии NikaS 2.2 с учётом возможностей Syncleo.

- Мобильная плашка занимает эталонные 168×58 px, использует отступы `12×14 px`, радиус 18 px и шрифты 16/13 px — как в панели S8 OMNI.
- Доступная сущность платформы Syncleo подтверждает живой локальный UDP-канал: первая строка становится зелёной и показывает «Локально».
- Заполненный снимок определяется минимум по двум независимым полям кондиционера: температуре блока, уставке и скорости вентилятора. Вторая строка показывает «Состояние получено», не заявляя неподтверждённую временную актуальность.
- Если UDP-канал доступен, но снимок ещё не получен, отображается «Локально / Ожидание данных».
- Если канал потерян после полученного снимка, отображается «Нет связи / Данные устарели». До первого снимка — «Нет связи / Нет данных».
- Зелёная точка в выборе кондиционера появляется только для подтверждённого локального канала с полученным снимком; красная — при потере канала; серая — во время ожидания данных или при неподтверждённом источнике.

Почему текст отличается от S8 OMNI: интеграция пылесоса публикует отдельный возраст телеметрии, а Syncleo такого timestamp не предоставляет. Поэтому климатическая панель не использует формулировку «Данные актуальны» без доказательства времени последнего принятого sample.
