# UI 1.4.21 / интеграция 0.1.50

Закрытие A12 аудита без изменения утверждённой компоновки Сводки и Управления.

- Разметка очередного состояния создаётся в отсоединённом `template`, после чего совместимые живые узлы обновляются на месте. Текущая карточка и переключатели кондиционеров больше не проходят через `innerHTML` на каждом обновлении `hass`.
- Иконка режима в переключателе переиспользуется, а не удаляется и создаётся заново.
- Первичное получение entity/area/label registry вызывает точечный `patch`, а не повторный `render` всей оболочки.
- Пустые placeholders статистики не очищают уже смонтированные графики; кэшированная история не возвращается через промежуточное состояние загрузки.
- Во время pinch/pan обновление по-прежнему откладывается и выполняется один раз после завершения жеста. При неизменной вкладке сохраняются `scrollTop`, `scrollLeft` и активный элемент.

Регрессия проверяет отсутствие live-записей в `devices.innerHTML` и `content.innerHTML`, сохранение совместимых узлов и history slots, точечное обновление текста/атрибутов и очередь обновления во время жеста.
