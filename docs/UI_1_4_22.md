# UI 1.4.22 / интеграция 0.1.51

Исправлена визуальная семантика связи при неизвестной свежести данных.

- «Локально / Нет данных» сохраняет каноническое двухуровневое значение: платформа Syncleo подтверждена, но достоверного времени последнего принятого пакета нет.
- Такое состояние теперь полностью нейтральное: фон, подпись и точка серые. Зелёный цвет не используется как неподтверждённый признак живой телеметрии.
- Точка рядом с названием кондиционера использует ту же модель: зелёная только для «Локально / Данные актуальны», красная для `unknown`/`unavailable`, серая при неизвестной свежести или источнике.
- Сохранённые Home Assistant значения при неизвестной свежести не превращаются в доказательство связи.
