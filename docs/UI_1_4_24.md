# UI 1.4.24 / интеграция 0.1.53

Предрелизное закрепление геометрии и автоматической проверки.

- Плашка имеет не только `min-height`, но и фактическую высоту 58 px.
- Текст использует эталонные размеры 16/13 px, `line-height: 1.05` и межстрочный интервал 3 px. Это устраняет скрытое увеличение высоты до 63–64 px из-за стандартного line-height браузера.
- На мобильной ширине 341–520 px зарезервировано 168 px; до 340 px — компактные 160 px для защиты названия режима от посимвольного переноса.
- В GitHub Actions устанавливается Chromium и выполняется `tests/summary-fit.browser.cjs`.
- Браузерный тест проверяет реальные `getBoundingClientRect()` плашки, посадку Сводки на типовых iPhone-размерах и отсутствие горизонтального переполнения.

Логика состояний из UI 1.4.23 не изменена.
