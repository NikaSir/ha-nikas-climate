# UI 1.4.15 / интеграция 0.1.43

Исправления по проверке пользователем UI 1.4.14:

- Старый стиль `.viewport.summary-fit` запрещал прокрутку. Новые правила разрешают вертикальную прокрутку рабочей области и естественную высоту содержимого. Примечание доступно ниже карточки. Исправлен также порядок установки переопределяющих стилей при первом render.
- В «Управлении» убрана принудительная высота карточки и автоматический отступ перед «Применить». Сверху комнатная температура и миниатюра прибора; далее уставка/качание, режимы, вентилятор, Ночной/Турбо и применение. Логика накопления и отправки команд сохранена.
- Графики используют существующий `hass.callApi` и `history/period`. `loadCardHelpers` больше не требуется. Источники совпадают со «Сводкой». Выбор 24 ч / 7 дней, единицы и временные отметки, минимум/максимум, разрывы для unknown/unavailable/пустого значения. Кэш запроса на минуту, состояния загрузки/пустой истории/ошибки с повтором.

Проверено локально:

- Node: состояния «Сводки», тип влажности, разбор ответа истории и разрывы графика.
- Chromium: реальное событие колеса прокручивает примечание в видимую область при 390×844 и 375×667; Header остаётся на месте.
- «Управление»: отсутствие переполнения, отступ до применения 16 px.
- Графики с полностью отсутствующим loadCardHelpers: оба источника, смена периода, ошибка API, кнопка повтора, пустой ответ.
- Синтаксис JS, git diff --check.

Браузерные снимки в images используют тестовые состояния и подставной ответ History API. Проверка с Recorder пользовательского HA и жестом прокрутки в iOS остаётся необходимой. Ветка подготовлена для проверки; установка на HA не выполнялась.
