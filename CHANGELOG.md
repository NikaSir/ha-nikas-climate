# Changelog

## 0.1.6 — 2026-09-05

- Статусные лампы `Зал / Веранда` синхронизированы по смыслу с основной плашкой «Связь»: состояние комнатного датчика больше не переводит лампу кондиционера в оранжевый при исправном локальном канале Syncleo.
- Первая страница «Сводка» уплотнена и зафиксирована без вертикальной прокрутки: температурный блок, полный отчёт режима и компактный 24-часовой график должны помещаться в рабочее окно.
- Скорости вентилятора переведены в один ряд из четырёх кнопок: Авто / Низкая / Средняя / Высокая.
- Управление единственной моторизованной створкой Ballu перенесено непосредственно к блоку уставки температуры.
- Сохранена логика NikaS: текущее состояние — голубое, целевое до «Применить» — зелёное.

## 0.1.5 — 2026-09-05

- Проведён повторный аудит соответствия NikaS Standard v2.2 по геометрии прокрутки.
- Исправлен критичный дефект iOS/HA: вытягивание рабочей области за верхнюю/нижнюю границу больше не должно передаваться host-контейнеру Home Assistant и запускать pull-to-refresh/сдвиг всей формы.
- Прокрутка закреплена исключительно за внутренним `.viewport`; Header, селектор устройств и нижнее меню остаются неподвижными.
- Добавлены `overscroll-behavior` и активное подавление touch/wheel scroll chaining на границах внутреннего viewport.
- В контракт v2.2 явно добавлены `scroll_chaining=false`, `pull_to_refresh=false`, `edge_overscroll=false`.

## 0.1.4 — 2026-09-05

- Возвращена кнопка `↻` в правую часть Header; она обновляет связанные сущности выбранного кондиционера и пытается перезагрузить его Syncleo config entry для повторного локального handshake.
- Реализована полная отложенная модель управления одной кнопкой «Применить»: уставка, HVAC-режим, вентилятор, створка, Night и Turbo.
- Все управляющие кнопки приведены к формату «иконка сверху / подпись снизу»; текущее состояние — голубое, целевое — зелёным.
- Модель жалюзи исправлена под фактический Ballu Lagoon: одна моторизованная наружная створка вверх/вниз; UI показывает только `Качание / Зафиксирована`, без фиктивных двух осей.
- Учтена односторонняя природа штатного ИК-пульта: его экран не считается источником фактического состояния после Wi-Fi-команд.
- На «Сводку» добавлен компактный график температуры за последние 24 часа из Home Assistant Recorder.
- Определение контрольного комнатного датчика переведено на приоритет: общий ярлык с climate-сущностью → то же Area → явный резервный entity_id.
- Полный отчёт режима на «Сводке» сохранён; плашка «Связь» остаётся только на первой странице.
- Диагностика дополнена config entry и пояснением поведения ИК-пульта/принудительного обновления.

## 0.1.3 — 2026-09-05

- На «Сводке» добавлен полный отчёт о текущем режиме работы: режим HVAC, вентилятор, жалюзи, ночной режим, Turbo и Δ датчиков.
- Ночной и Turbo определяются по родственным Syncleo-сущностям того же устройства через Entity Registry Home Assistant.
- Эталонная двухуровневая плашка «Связь» оставлена только на первой странице «Сводка»; с «Управления» и «Диагностики» удалена.
- Кнопки режимов на вкладке «Управление» получили информативные MDI-иконки над подписью.
- Диагностика дополнена состояниями Night, Turbo, Child Lock, Sound, Access Control, Backlight и Error для выбранного Syncleo-устройства.
- Статусная лампа peer-устройства теперь учитывает подтверждённый Syncleo Error.

## 0.1.2 — 2026-09-05

- Убраны отдельные системные подтверждения для каждой команды кондиционера.
- Управление переведено на отложенную модель: изменения режима и уставки сначала выбираются в интерфейсе, затем отправляются одной кнопкой «Применить».
- Текущее состояние режима подсвечивается голубым, целевое несохранённое состояние — зелёным.
- После применения и подтверждённого обновления Home Assistant зелёная цель становится текущим голубым состоянием.
- Уставка получила индикацию текущего значения и зелёную индикацию изменённой цели.

## 0.1.1 — 2026-09-05

- Панель перепроектирована по NikaS Specialized Panel UI Standard v2.2.
- Header приведён к геометрии и визуальному контракту S8 OMNI.
- Селектор двух кондиционеров вынесен в отдельный фиксированный ряд 52 px и получил статусные лампы.
- Плашка «Связь» заменена на двухуровневую эталонную: канал `Локально / Нет связи` и актуальность `Данные актуальны / Нет данных`.
- Рабочая область отделена от фиксированных Header, селектора и нижнего меню.
- На сводке контрольная температура помещения стала главным климатическим фактом; уставка и датчик внутреннего блока вынесены во вторичные метрики.
- Диагностика явно фиксирует `Syncleo UDP / LAN` и отсутствие требования WAN.

## 0.1.0 — 2026-09-05

- Создан автономный репозиторий NikaS Climate.
- Добавлена интеграция Home Assistant `nikas_climate`.
- Зарегистрирован маршрут `/dashboard-climate-v1/home`.
- Добавлен стартовый mobile-first интерфейс для двух кондиционеров Syncleo.
- Контрольная температура помещений привязана к `sensor.sensor_th_zb_11_temperature` и `sensor.sensor_th_zb_14_temperature`.
- Основной канал управления зафиксирован как локальный Syncleo UDP/LAN.
